## Codebase Patterns

### State Machine
- ALWAYS use can_transition_to() before setMode() - never bypass validation
- State transitions log in format: "State transition: X -> Y"
- Use Time.now() for transition timestamps, millis() for timeout tracking
- volatile keyword required for state variables accessed from interrupts

### Hardware
- Debounce ALL hardware state changes (10ms for detector, 5000ms for heater ready)
- delayMicroseconds() for precise timing under 1000us, delay() for longer
- Always check limit switches BEFORE motor movement
- Wake motor before movement, sleep after if not needed soon

### Cloud Operations
- Track cloud_operation_pending flag for timeout detection
- Retry with exponential backoff: base * retry_count
- Clear all tracking when cartridge removed
- Validate checksums on all downloaded data

### Serial Commands
- Parse as comma-delimited integers
- Log all command executions for diagnostics
- Check state machine before hardware commands
